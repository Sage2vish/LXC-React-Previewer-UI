# Repository Agent Guide

This repository is maintained through Codex, and this file is the root-level handoff for future sessions.

## Read First

Before any code or packaging work, read:

1. `CONTEXT.md`
2. `START_HERE.md`
3. `TASKS.md`
4. `FEATURES.md`
5. `CHANGELOG.md`
6. `VSCODE_PUBLISH.md`
7. `README.md`
8. `CONTRIBUTING.md`
9. `sample/README.md`

## Operating Rules

- Keep `TASKS.md` as the working backlog.
- Keep `CONTEXT.md` as the durable project memory.
- Keep `FEATURES.md` and the changelog files aligned with the release line.
- Do implementation work first when the task is code, packaging, or behavior.
- Update the Markdown memory files only when the task changes scope or completes a tracked item.
- Commit and push verified work.
- Preserve the preview-helper scope. Do not expand into a drag-and-drop editor unless the task explicitly asks for it.
