## Rules

- Treat `TASKS.md` as the live implementation backlog.
- Treat `FEATURES.md` as the release feature map.
- Treat `CHANGELOG.md` as the release history.
- Treat `VSCODE_PUBLISH.md` as the publish checklist.
- Treat `README.md` as the public product-facing document.
- Do the work first when the task is clear.
- Do not pause to rewrite Markdown unless the task explicitly asks for docs.
- After completing work, commit and push the changes unless blocked by external auth or permissions.
- Keep the current release line and decisions in sync across the docs.

## Current Decisions

- The extension is a VS Code preview helper for React Native `.tsx` files.
- The project is open source and maintained under Lexvora Consulting.
- The implementation should stay preview-focused, not become a full drag-and-drop editor yet.
- The UI should keep the preview controls, device selector, and settings flow visible inside the preview experience.
