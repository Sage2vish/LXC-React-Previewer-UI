# Project Context

## Project Name

LXC React Previewer UI

## Brand

Lexvora Consulting

## Mission

Preview React Native `.tsx` screens beside their source code inside VS Code without requiring an emulator or simulator.

## Scope

- Keep the extension preview-focused
- Keep it installable as a `.vsix`
- Keep the public identity open source
- Keep the workflow centered on source-side UI review

## Non-Goals

- Full drag-and-drop screen editor
- Canvas-based layout builder
- JSX generation from drag gestures
- Component tree editor
