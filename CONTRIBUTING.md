# Contributing

Thanks for helping with LXC React Previewer UI.

## Before You Start

- Read `README.md`
- Read `CONTEXT.md`
- Read `TASKS.md`

## Project Rules

- Keep changes focused on the previewer
- Prefer small, reviewable commits
- Update the task list when work changes
- Preserve Lexvora Consulting attribution
- Keep the open-source tone clear and respectful

## macOS Notes

- The main development environment is macOS
- Verify file paths work correctly on macOS
- Check that packaging works on a Mac before release

## Windows Notes

- Windows contributors are welcome
- Please confirm path separators and packaging behavior
- Report any install issues in VS Code on Windows

## Shared Frameworks Folder

Reusable packages, SDKs, or local development helpers may live in:

`/Users/SageVish/Documents/Development Work/frameworks`

If you add shared tooling there, mention it in the pull request or issue so others can reuse it.

## What Good Contributions Look Like

- Clear intent
- Small scope
- Updated documentation
- Working build or a clear explanation of what remains

## When You Finish

- Update `TASKS.md`
- Update `CONTEXT.md` if decisions changed
- Mention validation steps in the pull request
